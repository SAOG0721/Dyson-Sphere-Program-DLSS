# Changelog

## 0.6.3 - 2026-08-27

- Added BepInEx 5.4.17 x64 and its required runtime files to the release archive.
- Changed the release package to an all-in-one ZIP that needs no separate prerequisite download.
- Reworked the Chinese and English user instructions for installation, updating, removal, controls, and troubleshooting.

- Assigned `F8` to DLSS enable/disable and `F9` to the control panel.

## 0.5.2 - 2026-08-15

- Initial public release with DLSS Super Resolution and DLAA modes.
